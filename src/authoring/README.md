# authoring/ — the AI Course Authoring modal, vendored

Copied from [ai-course-authoring-flow](https://github.com/vliakhova-cmd/ai-course-authoring-flow),
which is where it is designed and maintained.

It used to be imported across a folder boundary. That worked while the
prototypes shared a parent directory and stopped working when each became its
own repository — so the modal lives here, and Create Course → AI Course
Authoring opens it **over** the study profile rather than navigating away to
another app's content library.

Sync by copying the files again; nothing here is edited locally.
